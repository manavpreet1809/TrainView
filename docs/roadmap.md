# TrainView roadmap

1. Foundation: branding, reproducible configuration, setup documentation, clean checks.
2. Demo data and onboarding.
3. Activity import reliability.
4. Accurate metrics and reporting windows.
5. Monitoring data integration.
6. Dashboard experience.
7. Charts and analysis.
8. Workout explorer.
9. Workout details.
10. GPS processing.
11. Interactive maps.
12. User-entered training goals.
13. Grounded AI coaching.
14. Quality and deployment.
15. Portfolio release.

The planning target is 20 coherent commits per stage. Commit counts are not a substitute for verified behavior. Tests and documentation accompany implementation throughout.
